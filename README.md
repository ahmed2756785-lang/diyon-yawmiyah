# ديون يوميه

تطبيق Flutter عربي (RTL) لتسجيل ديون العملاء بالصوت أو يدويًا.

## البناء عبر GitHub Actions
1. ارفع كل محتويات هذا المجلد إلى مستودع GitHub (فرع `main`).
2. افتح تبويب **Actions** ← **Build Signed APK** (يعمل تلقائيًا عند كل push أو يدويًا).
3. بعد انتهائه نزّل الـ Artifact باسم **Diyon-Yawmiyah.apk** (ملف مضغوط بداخله الـ APK).

> مجلد `android/` يُولَّد تلقائيًا أثناء البناء ثم تُطبَّق عليه إعدادات `tool/`.
> لتحديث التطبيق فوق نسخة مثبّتة بدون حذفها، أضف Secrets: `KEYSTORE_BASE64` و`KEYSTORE_PASSWORD`
> ليستخدم البناء نفس مفتاح التوقيع في كل مرة.
